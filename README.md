# 六级词汇

给自己背 CET6 词汇用的单文件网页应用。无需编译、无需账号、无后端，
学习记录只存在浏览器本地（localStorage）。

引擎沿用「小狐狸侦探·单词」(`E:\Cowork\Claude\kid-vocab`) 那套，但**去掉了全部奖励系统**：
没有线索、没有狐狸、没有图鉴和蛋。留了三个实打实的东西——**英译中 / 中译英 / 句子练习**，
外加一本错词本。

> 和 kid-vocab、积分小天地都是**互相独立**的应用，不共用数据，别接到一起。

## 词库

**2220 个 CET6 词条**（几个同形词合并后），每条带 IPA 音标、中文释义、完整释义，
其中 **2178 条配了英文例句**。

数据来源：

| 内容 | 来源 | 许可 |
|------|------|------|
| 词表 / 音标 / 释义 | [mahavivo/english-wordlists](https://github.com/mahavivo/english-wordlists) 的 `CET6_edited.txt` | 该仓库未标注，仅自用 |
| 例句 | [Tatoeba](https://tatoeba.org) 英文语料（经 `downloads.tatoeba.org` 导出） | CC-BY 2.0 FR，需署名 |

**例句是 Tatoeba 众包语料，质量参差。** 看着别扭的直接改 `原始数据/sentences.txt`
那一行再 `inject` 就行（详见下面「改例句」）。生成时已经过滤过一批：
含数字的、含性/脏话/血腥/毒品/醉酒字眼的、目标词出现不止一次的，都不要。

## 怎么用

### 本机开（改完立刻能看）

双击目录里的 **`start-server.bat`**，窗口里会列出该在手机／平板上输入的网址
（比如 `http://192.168.1.23:8011`）。手机连同一个 Wi-Fi，浏览器打开那个网址。
用的时候**那个黑窗口别关**。

> ⚠️ 端口用 **8011**：8000 是积分小天地，8010 是小狐狸侦探·单词。
> Windows 上 Python 允许两个程序绑同一个端口且不报错，会以为打开的是这个其实是另一个。

### 在线版

发布到 GitHub Pages 后**电脑不用开机也能用**，断网也能用（离线缓存只在 https 下才让注册，
这是它比本机模式强的地方）。

网址是 <https://nataliewang118.github.io/cet6-vocab/>。

改完发布就三步：

```
git commit -am "改了什么"
python _push_api.py
```

**不要用 `git push`，推不上去。** 这台机器上 `github.com` 被墙（连 443 超时），
但 `api.github.com` 是通的，所以 `_push_api.py` 走 Git Data API 把当前 commit 送上去。
它每次都是**拿远端最新 + 本地 HEAD 打一条新 commit**，不是覆盖，历史是连着的。

> 分支是 `master`（跟积分小天地、小狐狸侦探一致），Pages 从根目录发布。

推完约 1 分钟生效。浏览器里**打开两次**才是新的
（第一次拿缓存，第二次才轮到后台取回的版本）——不是没生效。

## 三个方向

首页「开始学习」进去先选练哪个：

- **英译中**（常开）：看英文选中文。答对自动发音并自动下一题。
- **中译英**（要先热身）：看中文选英文。**今天还没刷英译中时它是灰的、带把锁**——
  因为它的题就是从英译中答对的词里攒出来的。
  - 英译中**答对**的词进队首；今天没轮到的留在队里，**跨天不清**，明天接着考。
  - 考到就出队（答对答错都出）。所以"当天答对的优先、有余力再补昨天的存货"不用额外写逻辑。
  - **不自动发音、不给音标**——那等于把答案递过去。答完才念，答完「再听一遍」才解禁。
  - 选项优先挑**同首字母、长度接近**的词当干扰项（形近才考得出拼写）。
- **句子练习**（常开）：给一句英文、把那个词挖空，四选一。全程没有中文提示。
  - 答对念**整句**；答错只念那个词，并把词填回整句给你看，再补一条完整释义。
  - 选项跟中译英一样优先挑形近词。

## 出题与排期

- **只限时间，不限题量**。时间到了才结算；一批题刷完会自动续一批，直到时间用完。
- **每个词有 0–5 级掌握度**，答对升级、间隔拉长（10 分钟 → 1 天 → 3 天 → 7 天 → 14 天 → 30 天）。
  **答错不降级**，只把复习提前到明天，避免打击。
- **每天新词**：受设置里「每天新词」限制（默认 20，可调 5–100）。这是**按天**算的，
  刷完一轮再开一轮，当天额度用完就不再出新词，但复习照旧。
- **送分题**：已经答熟的词会随机撒几个进来，免得整轮都是生词。
- 新词额度用完又没有到期复习时，拿学过的词兜底，不会让一轮空着开始。

## 错词本

首页「错词本」进去看两类：

- **待攻克的词**：答错过的词自动进来，**累计答对 3 次才出本**。中途再答错**进度不清零**
  （已出本的又答错才重新开案，从 0 开始）。词条下面的小圆点就是进度。
- **反应慢的词**：从没答错、但上次答对得反常地慢的词，用黄色标出。
  「慢」是跟你**自己的平均速度**比（`耗时 > max(你的平均 × 1.6, 2.5 秒)`）；
  头 5 题还没攒出基线时用绝对阈值兜底（超过 6 秒算慢）。
  超过 90 秒当成"人走开了"丢掉；15–90 秒照算慢，但**不进基线**（那是真不会，不是变慢了）。
  慢答对只是这一级不算数、按当前级别重排——反馈仍然是"答对"。
- 每行右下角写着**它是几时进来的**（刚刚 / 今天 / 昨天 / 3 天前 / 9-18）。
- 点词条可以再听一遍发音。
- **「集中练」**：只刷这一类，练到"累计答对 2 次"就停——攻克（3 次）留给正常轮。
  限时跟设置里的每轮时长走。

## 改词表

词表源文件是 `原始数据/words.txt`（一行一词，格式 `单词 [音标] 词性. 释义`）。
改完跑：

```
python _build_words.py
```

它解析后灌进 `index.html` 的 `WORDS` 常量。**不要手改 index.html 里的 WORDS**，会被下次生成覆盖。

> ⚠️ **加词可以，删词和改顺序要当心。** 单词的内部编号（`w0`、`w1`…）是按解析后的顺序生成的，
> 掌握度、复习排期、错词本全是按这个编号存的。改动会让编号整体错位，
> 进度挂到别的词上。真要大改，先在设置里导出备份，改完再导入是**对不上的**——
> 得先清空记录。加词放在文件里相对靠后的位置最安全。

`_build_words.py` 末尾会打印「解析不了 N 行」和「无音标 N 个」。
现在都是 0；如果你加了词又出现非零，说明新行的格式脚本认不出来，看看打印出来的那几行。

## 改例句

例句在 `原始数据/sentences.txt`，一行一句：

```
abandon | The captain gave the order to abandon the ship. | -
```

中间那列写**完整句子**，`___` 是 `inject` 时自动挖的，别自己写。
第三列是中文，现在都留 `-`（句子练习不显示中文），留着是为了以后要用。

重新生成初稿：

```
python _build_sents.py pick      # 从 Tatoeba 语料里重新给每个词挑一句
python _build_sents.py inject    # 灌进 index.html 的 SENTS
```

`pick` 需要 `_data/eng_sentences.tsv.bz2`（Tatoeba 英文语料，约 30MB，见脚本头部注释里的下载地址）。
`inject` 会先对账（词必须在词表里、词必须在句子里、挖空必须成功、句子不能太长），
过了才灌。**不要手改 index.html 里的 SENTS**，会被下次生成覆盖。

**没例句的词不影响使用**——它只是不进句子练习，英译中／中译英照常。

## 跑测试

改完 `buildPool` / `nextQ` / `answer` / `caseList` 之后跑一遍，别靠肉眼：

```
python _test.py
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless=new \
  --disable-gpu --virtual-time-budget=9000 \
  --user-data-dir="E:\Cowork\Claude\cet6-vocab\_edgeprof" \
  --dump-dom "file:///E:/Cowork/Claude/cet6-vocab/_test.html" | grep -o "<title>[^<]*"
```

> **路径要给 `file://` 全路径。** 直接写 `_test.html` 会被 Edge 当成主机名
> （去连 `http://_test.html/`），DOM 出来是空页面，看着像"一个断言都没跑"。
> `--user-data-dir` 别省，不然跟你正开着的 Edge 抢配置。

`_test.py` 跑八段：先拿**真词库**验数据格式并连答 60 题（看会不会抛），
再换成自己造的**假词库**验出题池（每日额度、跨天重置、exclude、送分题上限、池内不重复），
再验 SRS 排期（升级、封顶、答错不降级、排到明天），
再验中译英（方向锁、队列进出、跨天保留、题干是中文、选项全英文、不给音标、考到出队、死 id 剔除），
再验句子练习（只收有例句的词、题干挖空、选项全英文、答错填回整句并给释义），
再验错词本（立案、进度不清零、3 次出本、已出本再答错重开案、慢词判定），
再验结算与统计，最后验音效不削顶。

看 `<title>` 里全 PASS、且末尾 `ERR:` 为空才算过。

## 备份

学习记录存在浏览器 localStorage 里。设置页可以**复制备份**成 JSON，换设备或误删时导入恢复。
浏览器在存储紧张时可能清掉 localStorage，**建议偶尔备份一次**。
