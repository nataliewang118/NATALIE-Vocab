# NATALIE的词汇库

给自己背 CET4 / CET6 词汇用的单文件网页应用。无需编译、无需账号、无后端，
学习记录只存在浏览器本地（localStorage）。**四级和六级装在同一个 App 里，首页左上角切换。**

引擎沿用「小狐狸侦探·单词」(`E:\Cowork\Claude\kid-vocab`) 那套，但**去掉了全部奖励系统**：
没有线索、没有狐狸、没有图鉴和蛋。留了三个实打实的东西——**英译中 / 中译英 / 句子练习**，
外加一本错词本。

> 和 kid-vocab、积分小天地都是**互相独立**的应用，不共用数据，别接到一起。

## 两个级别

一份词库，每个词带一个级数：`lv='4'` 只在四级、`'6'` 只在六级、`'46'` 两边都有。

| | 词数 | 说明 |
|---|---|---|
| 四级（默认） | **4537** | 四级独有 3494 + 重合 1043 |
| 六级 | **2220** | 六级独有 1177 + 重合 1043 |
| 词库合计 | 5714 | 重合的 1043 个词只存一份 |

**进度按单词本身存，不按下标。** 所以：

- 切级别**不丢任何进度**，切回来照旧。
- 重合的 1043 个词**两级共享掌握度**——在四级背熟的词，切到六级就已经是熟的。
- 错词本、待复习数、学习进度、中译英队列**都是按当前级别算的**，不会拿六级的词来烦四级的人。
- **例外：今日统计（今日已答题 / 正确率 / 每天新词额度）两级共用。** 那是"今天一共学了多少"
  的预算，不是单个级别的。所以四级刷掉 20 个新词，切到六级会发现今天的新词额度也用完了。

## 词库

**5714 个词条**（含并级别后的去重），每条带 IPA 音标、中文释义、完整释义，
其中 **5645 条配了英文例句**（四级 99.2%、六级 98.4%）。8 个词没有音标（`a`、`I`、`well-known` 这类，
源文件里本来就没给，也用不着）。

数据来源：

| 内容 | 来源 | 许可 |
|------|------|------|
| 词表 / 音标 / 释义 | [mahavivo/english-wordlists](https://github.com/mahavivo/english-wordlists) 的 `CET4_edited.txt` + `CET6_edited.txt` | 该仓库未标注，仅自用 |
| 例句 | [Tatoeba](https://tatoeba.org) 英文语料（经 `downloads.tatoeba.org` 导出） | CC-BY 2.0 FR，需署名 |

**来源词表里有一批假字**，`_build_words.py` 会在解析时修掉，别以为是脚本写错了：
西里尔的 `ә`/`ү`/`є` 冒充 `ə`/`ʌ`/`ɛ`；**496 处用积分号 `∫` 冒充 `ʃ`**（Symbol 字体遗留）；
私用区字符冒充方括号，还常跟真方括号**叠在一起**。修完音标才对。

**例句是 Tatoeba 众包语料，质量参差。** 看着别扭的直接改 `原始数据/sentences.txt`
那一行再 `inject` 就行（详见下面「改例句」）。生成时已经过滤过一批：
含数字的、含性/脏话/血腥/毒品/醉酒字眼的、目标词出现不止一次的，都不要。

## 怎么用

### 本机开（改完立刻能看）

双击目录里的 **`start-server.bat`**，窗口里会列出该在手机／平板上输入的网址
（比如 `http://192.168.1.23:8011`）。手机连同一个 Wi-Fi，浏览器打开那个网址。
用的时候**那个黑窗口别关**。

> ⚠️ 端口用 **8011**：8000 是积分小天地，8010 是小狐狸侦探·单词。
> Windows 上 Python 允许两个程序绑同一个端口且不报错，会以为打开的是这个其实是另一个。

### 在线版

发布到 GitHub Pages 后**电脑不用开机也能用**，断网也能用（离线缓存只在 https 下才让注册，
这是它比本机模式强的地方）。

网址是 <https://nataliewang118.github.io/NATALIE-Vocab/>。

> 仓库以前叫 `cet6-vocab`、页面叫「英语词汇」，2026-09-22 改成现在这个。
> ⚠️ 仓库名只能用 ASCII——中文会被 GitHub **静默删掉**（不报错，不报错这点最坑）。
> 所以「NATALIE的词汇库」只出现在 App 里，仓库/网址里是 `NATALIE-Vocab`。

> ⚠️ **旧网址 <https://nataliewang118.github.io/cet6-vocab/> 现在是 404，不会跳转。**
> GitHub 只给**仓库页面**做改名跳转，**Pages 站点不跳**（实测过）。
> 手机主屏上要是加过旧地址的图标，删掉重新用新网址加一次。

**好消息：学习记录不会丢。** localStorage 是按**域名**存的（`nataliewang118.github.io`），
跟后面的路径无关，所以改仓库名不影响进度。

改完发布就两步：

```
git commit -am "改了什么"
git push
```

> 分支是 `master`（跟积分小天地、小狐狸侦探一致），Pages 从根目录发布。

推完约 1 分钟生效。**在线时每次打开都会去问服务器**，所以刷新一下就是新的，不用打开两次。

> ⚠️ 这条以前不是这样。原来 SW 用的是 stale-while-revalidate，天生"改完要打开两次才生效"；
> 更坑的是 GitHub Pages 给 HTML 发的 `Cache-Control` 是 `max-age=600`，SW 后台那次重取
> **会命中浏览器自己的 HTTP 缓存**，于是十几分钟内怎么刷都刷不出新的。
> 现在 SW 是 **network-first**，所有 fetch 都带 `cache:'no-cache'` 强制绕过 HTTP 缓存，
> 拿不到网络才退回缓存（所以断网照旧能用）。另外新 SW 接管时会**自动刷一次页面**，
> 就是为了不再出现"明明推上去了却看不到"。
>
> **已经被旧缓存卡住的设备**：这个更新本身也得走一次老逻辑，所以那台设备要
> **强刷一次**（电脑 `Ctrl+F5`／`Ctrl+Shift+R`；手机就在隐私设置里清掉该站点数据），
> 或者**彻底关掉再打开两次**。之后就不会再遇到这事了。

### 这台机器的网络（重要）

`github.com` 被**半封**：连接能建立、HTTP 头也能收到，但数据传到一半就卡死到 12 秒超时。
所以**用 HTTPS 的 `git push` 是走不通的**。`api.github.com` 反而完全正常。

绕法是走 **SSH 的 443 端口**（`ssh.github.com` 没被封）。已经配好了：

- `~/.ssh/config` 把 `github.com` 指到 `ssh.github.com:443`
- 密钥 `~/.ssh/id_ed25519`，挂在这个仓库上的是 **deploy key**（仓库专属，不是账号级，权限更小）

⚠️ **只对这一个仓库有效。** 同一把公钥挂不到第二个仓库（GitHub 报 `key is already in use`），
积分小天地和小狐狸侦探要用的话得各自生成一对密钥。

`_push_api.py` 留着当**备用通道**：万一 SSH 也抽风，`python _push_api.py` 能从 API 那边推上去
（它读本地 HEAD、走 Git Data API，历史是接着的，不是覆盖）。

## 三个方向

首页「开始学习」进去先选练哪个：

- **英译中**（常开）：看英文选中文。答对自动发音并自动下一题。
- **中译英**（要先热身）：看中文选英文。**今天还没刷英译中时它是灰的、带把锁**——
  因为它的题就是从英译中答对的词里攒出来的。
  - 英译中**答对**的词进队首；今天没轮到的留在队里，**跨天不清**，明天接着考。
  - 考到就出队（答对答错都出）。所以"当天答对的优先、有余力再补昨天的存货"不用额外写逻辑。
  - 队列**存两级所有的词**，但一轮只考当前级别的——切回去存货还在。
  - **不自动发音、不给音标**——那等于把答案递过去。答完才念，答完「再听一遍」才解禁。
  - 选项优先挑**同首字母、长度接近**的词当干扰项（形近才考得出拼写）。
- **句子练习**（常开）：给一句英文、把那个词挖空，四选一。**答题时**没有中文提示。
  - 答对念**整句**；答错只念那个词，并把词填回整句给你看，再补一条完整释义。
  - **答完（对错都一样）在下面给出整句的中文翻译**，读完点「继续」再翻页——
    900 毫秒读不完一句话，所以**有中文可读时不再自动跳**。没配中文的句子照旧自动跳。
  - 选项跟中译英一样优先挑形近词。

## 上一题（回看）

答题页底下那排键，中间是「再听一遍」，两边是回看用的：

- **← 上一题**：把**刚答完的那题**原样调出来——题面、四个选项、当时标的正误、当时的反馈，
  连「连对几题」都是那一刻的数字。再点一次继续往前翻，翻到最早一题就灰掉。
- **返回 →**：回到当前这道接着答。只在回看时出现。
- 回看是**纯只读**：选项全部点不动，掌握度、错词本、待复习一概不动，也不往历史里塞东西。
  想改答案没有入口——要重来只能等它下次被排到。
- 回看时「再听一遍」念的是**回看那一题**的词（句子练习念整句），不是当前这题。
- 当前这题还没答就去翻回看的话，返回时**计时重新开始**，免得翻看的时间被当成"反应慢"。
- 历史只在内存里，**不写 localStorage**——一轮结束或刷新页面就没了。

## 出题与排期

- **只限时间，不限题量**。时间到了才结算；一批题刷完会自动续一批，直到时间用完。
- **每个词有 0–5 级掌握度**，答对升级、间隔拉长（10 分钟 → 1 天 → 3 天 → 7 天 → 14 天 → 30 天）。
  **答错不降级**，只把复习提前到明天，避免打击。
- **每天新词**：受设置里「每天新词」限制（默认 20，可调 5–100）。这是**按天**算的，
  刷完一轮再开一轮，当天额度用完就不再出新词，但复习照旧。**额度两级共用。**
- **送分题**：已经答熟的词会随机撒几个进来，免得整轮都是生词。
- 新词额度用完又没有到期复习时，拿学过的词兜底，不会让一轮空着开始。

## 错词本

首页「错词本」进去看两类（**只列当前级别的词**）：

- **待攻克的词**：答错过的词自动进来，**累计答对 3 次才出本**。中途再答错**进度不清零**
  （已出本的又答错才重新开案，从 0 开始）。词条下面的小圆点就是进度。
- **反应慢的词**：从没答错、但上次答对得反常地慢的词，用黄色标出。
  「慢」是跟你**自己的平均速度**比（`耗时 > max(你的平均 × 1.6, 2.5 秒)`）；
  头 5 题还没攒出基线时用绝对阈值兜底（超过 6 秒算慢）。
  超过 90 秒当成"人走开了"丢掉；15–90 秒照算慢，但**不进基线**（那是真不会，不是变慢了）。
  慢答对只是这一级不算数、按当前级别重排——反馈仍然是"答对"。
- 每行右下角写着**它是几时进来的**（刚刚 / 今天 / 昨天 / 3 天前 / 9-18）。
- 点词条可以再听一遍发音。
- **「集中练」**：只刷这一类，练到"累计答对 2 次"就停——攻克（3 次）留给正常轮。
  限时跟设置里的每轮时长走。

## 改词表

两个源文件，改完都跑一遍：

```
原始数据/cet4.txt
原始数据/cet6.txt        ← 一行一词，格式 `单词 [音标] 词性. 释义`
python _build_words.py
```

它把两个表解析、合并后灌进 `index.html` 的 `WORDS` 常量。重叠的词只留一份，
**释义取四级那份**（更短），只把级数并成 `46`。
**不要手改 index.html 里的 WORDS**，会被下次生成覆盖。

> ✅ **现在加词、删词、改顺序都安全了。** 单词的内部 id 就是**单词本身（小写）**，
> 不是解析顺序的下标——这是为了能装两个级别才改的。所以改词表不会让进度错位。
> 唯一要守的规矩：**同一个单词不能在表里出现两次**（`_build_words.py` 会直接报错退出），
> 单词里也不能有引号或尖括号（id 要进 HTML 属性）。

`_build_words.py` 末尾会打印各级词数、「没音标的 N 个」、「同释义的 N 组」、「解析不了的 N 行」。
现在解析不了的是 29 行，全是 A/B/C 分节字母和几个缩写行——正常的，不是坏了。
如果你加了词又冒出新的解析失败行，脚本会把前 8 行原样打出来，照格式改源文件就行。

## 改例句

例句在 `原始数据/sentences.txt`，一行一句：

```
abandon | The captain gave the order to abandon the ship. | 船长下令弃船。
```

中间那列写**完整句子**，`___` 是 `inject` 时自动挖的，别自己写。
第三列是**整句中文翻译**，句子练习答完就显示它。5645 句**全都翻好了**，想改哪句
直接改那一行再 `inject`；留 `-` 就是这题答完不给中文。

```
python _build_sents.py pick      # 从 Tatoeba 语料里重新给每个词挑一句
python _build_sents.py zh-merge  # 把 _tr/out_*.tsv 的翻译并回第三列
python _build_sents.py inject    # 灌进 index.html 的 SENTS 和 TRANS
```

`pick` 需要 `_data/eng_sentences.tsv.bz2`（Tatoeba 英文语料，约 30MB，见脚本头部注释里的下载地址）。
**这步慢**——要扫一遍上百万句的语料，五分钟起步，别以为卡死了。
`inject` 会先对账（词必须在词表里、词必须在句子里、挖空必须成功、句子不能太长），
过了才灌。**不要手改 index.html 里的 SENTS / TRANS**，会被下次生成覆盖。

> ⚠️ **`pick` 会按单词重新排序并重挑句子**，而 `_tr/` 里的翻译是**按行号**对上的——
> 跑完 `pick`，行号就跟旧翻译错位了，这时 `zh-merge` 会直接报「序号找不到对应行」，
> 不会错并。（翻译那一批是 12 个分块文件 `_tr/out_NN*.tsv` 拼起来的，
> `_tr/` 整个在 `.gitignore` 里，不入库——译文的正本在 `sentences.txt`。）
>
> 好在 `pick` 现在**会把句子没变的那些译文原样留住**（以前会一律冲成 `-`），
> 所以重挑之后只是换过句子的词缺中文。真缺了要么自己补，要么按
> `_tr/in_*.tsv` 那种「序号`<TAB>`英文句子」的格式导出来再翻一遍。

**没例句的词不影响使用**——它只是不进句子练习，英译中／中译英照常。

## 备份

学习记录存在浏览器 localStorage 里（键是 `cet.v2`）。设置页可以**复制备份**成 JSON，
换设备或误删时导入恢复。浏览器在存储紧张时可能清掉 localStorage，**建议偶尔备份一次**。

> ⚠️ 从**旧版**（只有六级的那个，键是 `cet6.v1`，词 id 是 `w0`/`w1` 这种下标）导出的备份
> **不能导入**——id 体系变了，对不上。那份进度只能重来。

## 到点提醒（Windows）

`_remind.ps1` 是个计划任务的脚本：**工作日 10:30 和 17:00** 弹一个框问「现在就开始？」，
点「是」直接打开上面那个网址。装它的机器上已经建好了，任务名叫 `NATALIE背单词`。

```
powershell -ExecutionPolicy Bypass -File _remind.ps1 -Setup          # 重建任务（换时间/换电脑）
Unregister-ScheduledTask -TaskName 'NATALIE背单词' -Confirm:$false   # 不要了
Get-ScheduledTaskInfo -TaskName 'NATALIE背单词'                      # 看下次什么时候响
```

嫌时间不对就改脚本里 `@('10:30','17:00')` 那一行再 `-Setup` 一次（`-Force` 会覆盖旧的）。

几个已经踩过的点，改的时候别踩回去：

- **脚本必须存成 UTF-8 带 BOM。** PowerShell 5.1 读不带 BOM 的文件会按 GBK 解，中文全变乱码。
- **写这个文件的时候小心 `\v`。** `WindowsPowerShell\v1.0` 里的 `\v` 在 Python 非 raw 字符串里
  是**垂直制表符**——路径里混进一个控制字符，`Register-ScheduledTask` 会报
  "Illegal xml character"，而且报错指着任务名，看着像中文名的锅，其实不是。用 raw 字符串写。
- `-AllowStartIfOnBatteries`：不加的话笔记本用电池时**根本不会触发**。
- `-StartWhenAvailable`：关机/睡眠错过的，开机后补一次。
